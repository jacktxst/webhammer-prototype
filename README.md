# webhammer (early development)

webhammer plans to be a powerful, easy to use level editor. 

it's inspired by tools like trenchbroom and hammer, valve's editor
for source and goldsrc games.

key highlights of webhammer's current capabilities:

 - full web and mobile friendly interface
 - crate and modify textured brush based geometry
 - saving and loading maps
